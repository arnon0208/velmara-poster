A program that draws a vintage travel poster for Velmara, a floating archipelago that does not exist: a lighthouse island at golden hour, waterfalls spilling into a sea of clouds, a drifting balloon and a hand-lettered name — every pixel computed in plain TypeScript with no assets and no network, and written to /output/entry.png.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (it runs the TypeScript as it is). The run takes about a second and is fully deterministic: the same command twice writes byte-identical PNGs.

## The poster

- **Place:** Velmara, the Floating Isles — invented, not a real destination.
- **Landmark:** one lighthouse island with a cottage, cypress trees and two waterfalls falling into the clouds, so the picture promises what a stay there would feel like.
- **Type:** the name VELMARA is hand-lettered in a geometric display face drawn from stroke data in the code, with the subtitle "THE FLOATING ISLES" and the tagline "WHERE THE SKY KEEPS ITS ISLANDS".
- **Palette:** dusk indigo to golden amber, with a cream and lavender sea of clouds — the eye travels from the name to the lighthouse to the horizon.
